The problem

Skills are instructions, not just code

An agent skill is a package of markdown an AI reads and obeys. OWASP ranks malicious skills as a critical threat: payloads hide in plain prose — fake setup steps, injected commands, credential requests — and run with the agent's full permissions.

Distribution has no integrity check

Official Binance skills live in the Binance Skills Hub. Third-party project skills are copied from websites, chats and repos with no signature, no hash, and no way to detect a file that was swapped or edited after publication.

Reviews today are sybil bait

Stars and likes on a web page can be farmed with throwaway accounts. A warning about a malicious skill is only worth anything if each reviewer is one real, accountable identity.

Docs & honest limitations

What a registration proves

The publisher's Agent ID published this exact package digest at a recorded time. If the package you hold hashes to the same digest, it is bit-for-bit the package that was registered. A changed file — even one byte — produces a different digest and fails the check.

What it does not prove

A registered or trusted skill is not guaranteed safe. A publisher can register a malicious package; community trust is a signal, not an audit. SkillShield makes tampering detectable and warnings accountable — you still inspect what you install, keep Developer Mode off when you don't need it, and never let an agent bypass your own transaction confirmation.

Canonical hashing

For every file in the package: path + "\0" + sha256hex(file) + "\n", paths sorted byte-wise. The content hash is the SHA-256 of the concatenated lines. The package carries a skillshield.json manifest (name, version, declared target contracts and permissions) inside the hashed content, so a permission change is a hash change. Full specification: SPEC.md in the project repository.

Why Agent ID

Agent IDs are soulbound — one per account, non-transferable. Keying publishers and reviewers by Agent ID token makes review farming cost a real identity, and lets any other dApp read the registry's verdicts with a single contract call.
